The reference pages come from the repository itself at build time, so they cannot fall behind it.

- [Make targets](/reference/make-targets/) reads the `##` comments of `Makefile` and `mk/*.mk`, the same lines `make help` prints.
- The repository documents below are copied from `docs/` by `scripts/sync-docs.mjs` at every build. Their own links become site links, a code span that names another copied document becomes a link to it, and paths under `docs/milestones/evidence/`, `.lab/` and `results/` stay code, because those files exist only on the machine that ran the lab.
