This is an eight-slide, ten-minute lightning-talk draft. Open the HTML in a browser to use it offline. Use the previous/next buttons or the arrow keys to advance, and press **F** for fullscreen where supported. A URL fragment such as `#slide-5` opens that slide directly. Expand the speaker notes beneath each slide for timing and sources, or print to PDF for one slide per page.

The demo slide shows the verdicts and details of two lab runs of 2026-11-25, `20261125T121324Z` with the stale file and `20261125T121559Z` after the repair. It is not a terminal capture. `.site/tests/slides.test.mjs` compares the deck with the scenario spec, the break script and the stored excerpts of both runs, so `npm test` in `.site` fails when a check name, a run, a boot time or a source line on the deck no longer matches the repository.

The deck uses the [Restack design system](https://github.com/restack-ai/design-system) palette and typography.
