## 1. Where it runs

## 3. Image

`images/ibsim/Dockerfile` starts from the base image by digest. It replaces the base image's apt sources with the snapshot alone and installs the four packages at their locked versions. `apt-get update --error-on=any` fails the build when the snapshot is unreachable. The snapshot is HTTPS only and the base image has no CA bundle. So the build mounts the guest's bundle for that step alone. apt still checks every index against the Ubuntu archive keyring.

The image runs as `10001:10001`. Its entry point `rfl-ibsim` refuses to run without the read-only marker mount that only `guest.sh` adds. `LD_PRELOAD=libumad2sim.so` is set per process for OpenSM and each tool. Nothing sets it image wide.

`make track-b-image` copies `images/ibsim` and `tracks/b-ibsim` into the guest, builds there and compares the image ID with `ibsim.image`. It exits 1 when they differ.

## 5. Scenarios and checks

Each scenario has a spec under `tracks/b-ibsim/scenarios/` and parameters in `tracks/b-ibsim/config/scenarios.yaml`. `result_kind` is `ib-management-simulation`. A unit test pins each spec's check list to the list the runner records.

| Check | What it asserts |
|---|---|
| `image-pinned` | `rfl-ibsim:m4` in the guest is the `ibsim.image` pin |
| `container-locked-down` | A VM with the Track B marker on the locked kernel. The container is not privileged, has no network, no device, every capability dropped, no-new-privileges, a read-only root, AppArmor `docker-default`, read-only mounts and no image-wide `LD_PRELOAD`. Every process runs as UID 10001 |
| `subnet-up` | OpenSM logs SUBNET UP. Every sweep routes with the configured engine. `sminfo` shows SMINFO_MASTER at the SM host's LID |
| `topology-discovered` | `ibnetdiscover` finds exactly the nodes, kinds, port counts and links of the topology file |
| `lids-unique` | Every linked HCA port has a non-zero LID under LMC 0. No two ports share a LID |
| `port-states` | `iblinkinfo` shows each linked port Active/LinkUp facing its peer. Each unlinked switch port is Down/Polling |
| `routes-shortest` | `ibroute` of every switch forwards every endpoint LID out of a port one hop closer to it, and holds no LID nobody owns |
| `lid-reachability` | A LID-routed `smpquery nodedesc` from the SM host reaches every LID and gets the node's name |
| `fault-resweep`, `recovery-resweep` | ibsim accepts `Unlink` or `ReLink` of the fault port. OpenSM logs a new SUBNET UP within 60 s |
| `fault-topology`, `fault-routes`, `fault-reachability` | After the fault the fabric equals the topology without that link, reduced to what the SM reaches. Routes stay shortest on it. Routes over the failed link moved, or left with their LID. Cut-off LIDs stay silent |
| `recovered` | After the ReLink, discovery, port states, LIDs, routes and reachability equal the baseline |
| `no-container-left`, `host-untouched` | The run's container is gone. The host runs no simulator process and lists no Track B container, at the start and the end |

## 6. Routing engine

OpenSM 3.3.23 routes with minhop by default. It also supports updn, dnup, file, ftree, lash, dor, torus-2QoS, nue, dfsssp and sssp (`evidence/m4/probe/09-opensm-options.txt`). Each scenario passes its engine as `opensm -R`.

| Scenario | Engine | Why |
|---|---|---|
| B-01, B-02, B-03 | minhop | updn needs root switches. On these single-tier fabrics it logs `disabling UPDN algorithm, no root nodes were found` and falls back to minhop (failed runs `20261115T141931Z` and `20261115T141940Z`). Every route crosses at most one switch-to-switch link, so minhop cannot form a credit loop here. This last point is reasoning, not a measurement |
| B-04 | updn | Up/down routing is free of credit loops on any topology. In a two-tier fabric where each leaf reaches each spine, its paths are shortest. `routes-shortest` confirms that for all 768 routes. ftree also reached SUBNET UP on the healthy cel1 fabric, but rejected the degraded one with `ERR AB0B` and fell back to minhop (`evidence/m4/probe/12-engines-under-fault.txt`). updn routed through the fault and the recovery. All three sweeps of B-04 logged `updn tables configured` |

OpenSM 3.3.23 rejects the `no_fallback` engine option (`evidence/m4/probe/10-routing-engines-cel1.txt`). So a failed engine falls back to minhop and OpenSM keeps running. The `subnet-up` check fails a run whose log names any engine other than the configured one. The failed runs above show that check working.

`docs/milestones/evidence/m4/host-refusal.sh` runs the scenario commands directly on the host. It first puts stubs for docker, `systemd-detect-virt` and every simulator command on PATH, and each stub records any call. On the host (kernel 7.0.0-43-generic, `systemd-detect-virt --vm` prints none, no marker):

- All eight `guest.sh` subcommands exit 2 with `refusing to run: /etc/rfl/track-b-guest is missing, so this machine is not the Track B guest. ... On the host, run make track-b.`
- `rfl-ibsim fabric`, `tool` and `console` exit 2 with `This image runs only inside the Track B guest`.
- No call reached a stub. No simulator process ran on the host.

The log is `evidence/m4/host-refusal.log`. `tests/unit/test_ibsim_host_refusal.py` repeats the same refusal on every `make test`. `host-untouched` scanned the host process list and `docker ps` at the start and the end of every run, and found nothing each time.

## 9. What the simulation cannot show

- **Hardware and firmware.** No ConnectX HCA or QM9700 switch exists here. Nothing here shows switch firmware, VF GUIDs or LIDs, or the SR-IOV udev race.
- **Link layer.** ibsim reports every link as 4X SDR at 2.5 Gbps. The cel1 model says NDR. Link speed, width negotiation and physical errors are not simulated.
- **Data path.** MADs travel over ibsim's Unix socket through libumad2sim. No packet crosses a wire. No RDMA traffic and no IPoIB were tested.
- **Timing.** Convergence times below are observations of one simulator process inside one VM on a busy host. They do not predict a real fabric.
- **Scope of the SM.** One OpenSM attaches at one HCA with LMC 0. Partitions, QoS, multicast and SM failover were not checked. B-05 did not run.
